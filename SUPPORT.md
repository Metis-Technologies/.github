# Support

How to get help with **Metis Technologies** projects.

## 💬 Questions and discussions

Our product repositories are currently private and GitHub Discussions isn't enabled anywhere yet. For questions, open an issue on this `.github` repository. The `@metis-technologies.com` mailboxes are not active yet, so we do not list one here.

## 🐛 Bugs and feature requests

Our product repositories (beaflow and metis-website) are private, so external bug reports cannot be filed there. Open an issue on this `.github` repository, which is open to everyone, with the product name, a description and the steps to reproduce. Never include sensitive data in a public issue.

## 🔒 Security issues

See [`SECURITY.md`](SECURITY.md) — please report security issues privately.

## 📩 Commercial inquiries

For partnerships, hiring, or commercial use of our open work, see [metis-technologies.com](https://metis-technologies.com), or open an issue on this repository asking for a private contact.

## 🛠️ Response times

We are a small team (2 founders). Expect:

- **Issues**: triage within 5 business days
- **PRs**: first review within 7 business days
- **Security reports**: see [`SECURITY.md`](SECURITY.md)
